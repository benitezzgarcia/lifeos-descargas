# LifeOS · Descargas

Web pública de descargas de LifeOS para Android y Windows.

La página se publica en GitHub Pages. Los paquetes se distribuyen en Releases; no se guardan binarios grandes en el historial Git.

La versión 1.3.0 es de prueba. El APK requiere Android 7 o posterior y todavía necesita validación física. El paquete Windows puede quedar bloqueado por políticas de integridad (ffmpeg.dll). No desactives protecciones para ejecutarlo. Google sigue en modo de pruebas y necesita una cuenta autorizada.

La página no contiene copias de datos personales ni credenciales. Las fuentes y recursos conservan sus licencias en assets/. Las licencias del modelo y motores se incluyen en los paquetes descargables.
